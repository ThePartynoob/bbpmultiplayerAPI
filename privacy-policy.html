Terms of Service & Privacy

Baldi's Basics Plus Multiplayer (BBPM)
Community-Hosted via Google Cloud Platform (GCP)

1. Infrastructure & Optional Donations

This multiplayer mod utilizes a dedicated Google Cloud Compute Engine VM (E2-micro instance) to keep servers online. Please note the following funding terms:

  • Current Funding: The multiplayer infrastructure is currently operating on free introductory cloud credits. The mod is entirely free to play.
  • Future Sustainability & Donations: Once these credits run out, the hosting will transition to a paid model. To help extend the lifetime of the mod and ensure the servers stay online long-term, players have the option to donate toward infrastructure costs via Ko-fi. All contributions go directly toward keeping the virtual machine active.
  • Uptime Expectations: This is a "best-effort" community service. While the dedicated VM allows for persistent hosting, we do not guarantee 24/7 uninterrupted uptime.

2. Privacy & Network Security

We care about your network privacy. By routing gameplay data through a centralized cloud server instead of a Peer-to-Peer (P2P) network, your home network stays secure:

  • Hidden From Other Players: Your personal IP address is 100% hidden from all other players in the game. All traffic is safely masked by the Google Cloud server.
  • Host Data & Moderation: Currently, the developer does not view or store player IP addresses. However, because network identification may be required in the future to implement server-side moderation features (such as banning toxic or malicious players), connection data may be processed by the server system strictly for network security and administration purposes.
  • Data Protection: We do not collect, track, or sell your personal details. Any metadata generated during your session is temporary.

3. Usage Rules

To keep the server environment stable and affordable for everyone, users must agree to the following conditions:

  • No intentional automated attacks, packet flooding, or attempts to crash the virtual machine instance.
  • No execution of malicious cheats that corrupt server-side synchronization files or block others from joining.
  • Any activity that violates Google Cloud’s standard Acceptable Use Policy is strictly prohibited. Violations may result in a permanent ban.
